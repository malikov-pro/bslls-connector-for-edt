# Инструкции для агентов (opencode и др.)

Кодекс проекта — «чего не делать» и зоны осторожности: [CLAUDE.md](CLAUDE.md)
(этот файл — зеркало-указатель; загружай его первым).

«Как делать правильно» — скиллы в `.claude/skills/`:

| Скилл | Когда |
|---|---|
| `bslls-build-test` | сборка (`bash compile.sh`), установка p2 в EDT, ошибки lombok/установки |
| `bslls-architecture` | перед любой правкой кода — где что лежит |
| `bslls-new-check` | каталог диагностик (всё генерируется скриптом из v8std) |
| `bslls-ready-to-deploy` | работа закончена — финальный чек-лист перед «готово»/коммитом |

Референс чужих практик (не часть проекта): `_source/EDT-MCP`.
